# My Machine Learning Journey

Welcome to my repository tracking my progress in Artificial Intelligence and Machine Learning! 

This space is dedicated to hands-on practice, code implementation, and personal notes as I work through the book **"AI and Machine Learning for Coders" by Laurence Moroney**.

## About the Book
*AI and Machine Learning for Coders* is a practical guide focused on building models using **TensorFlow**. It provides a code-first approach to understanding computer vision, natural language processing, sequence modeling, and mobile/web deployment.

## Tech Stack & Tools
- **Language:** Python 
- **Framework:** TensorFlow & Keras 
- **Libraries:** NumPy, Matplotlib
